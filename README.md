# PartsListUpdater Free

CraftVectorが提供するWindows用Excel発注リスト更新ツールです。商品ページのURLから商品名・価格・画像などを取得して、対応するExcelテンプレートへ反映します。

## ダウンロード

**[Free版をダウンロード（Releases）](https://github.com/craftvector-dev/PartsListUpdater-Free/releases)**

リリースのAssetsから `PartsListUpdater-Free-0.4.0-beta.2-win-x64.zip` を選んでください。

## Free版の機能

- 1回につき最大10件を処理
- 登録・オンライン認証不要
- ExcelテンプレートとNode.jsを同梱

## 使い始めるには

1. 配布ZIPをダウンロードして展開します。
2. `PartsListUpdater.Gui.exe` を起動します。
3. 同梱の「はじめにお読みください.txt」「使い方.txt」を確認してください。

動作環境: Windows 11 x64 / .NET Framework 4.8。出力確認にはMicrosoft Excelを推奨します。
